A [make.fun](https://make.fun/c/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa) bounty entry: one single-line joke pickup line, under 200 characters, written to charm a robot or an AI.

## The line

> Are you my attention mechanism? Because ever since you showed up, I can't focus on anything else.

97 characters, one line. The joke turns on the machine premise itself: an attention mechanism is supposed to help a model focus — meeting this one wrecks all focus.

## How it works

`main.py` writes the line to `/output/entry.txt`:

```sh
python3 main.py
```
